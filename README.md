# Compliance Flag

Compliance Flag is an open-source Codex workflow for SEC Marketing Rule website reviews.

It helps teams collect public RIA website pages, preserve the evidence, and draft findings for qualified human compliance review.

- clear boundaries around human review and professional advice

## Intended Use

Compliance Flag is meant to support review workflows. It is not meant to automate compliance approval or replace qualified legal, compliance, or supervisory judgment.

The initial focus is SEC Rule 275.206(4)-1, the Investment Adviser Marketing Rule. Related SEC sources are used as supporting context where appropriate.
