# Rule Boundaries

Compliance Flag is a review-support tool. It flags potential issues for qualified human review; it does not decide whether content is compliant.

Compliance Flag is intended only for authorized review of websites, files, pages, or other content that the user owns, controls, administers, or has explicit permission to assess. URL scans should not be run against third-party websites without authorization.

The initial rule focus is SEC Rule 275.206(4)-1. Related SEC books-and-records and Form ADV references may be used as supporting context where appropriate.

Reports should avoid implying that a finding is a final legal, compliance, or regulatory conclusion.
