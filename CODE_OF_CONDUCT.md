# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants are expected to communicate respectfully, assume good intent, and keep discussions focused on improving the project.

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainers through the contact channels listed in `SUPPORT.md`.
