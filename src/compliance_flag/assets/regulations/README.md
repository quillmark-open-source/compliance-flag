# Regulatory Sources

This directory contains the bundled SEC regulatory source material used by Compliance Flag during scan-time prompt assembly.

The bundled files are intended to support reviewer-facing analysis of public Registered Investment Adviser marketing content. Findings should be grounded in enforceable SEC rule text, not industry best practices, staff guidance, informal standards, or non-SEC rules.

## Bundled Scan-Time Sources

| File | CFR Section | Description |
|---|---|---|
| `sec-rule-275-206-4-1-investor-marketing.md` | 17 CFR § 275.206(4)-1 | Investment adviser marketing rule: general prohibitions, testimonials and endorsements, third-party ratings, performance advertising, and definitions |
| `sec-rule-275-204-2-books-and-records.md` | 17 CFR § 275.204-2 | Books and records to be maintained by investment advisers |
| `sec-rule-279.md` | 17 CFR Part 279 | Forms prescribed under the Investment Advisers Act, including Form ADV and Form PF |
